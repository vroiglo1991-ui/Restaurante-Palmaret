# Auditoría y Optimización SEO Web (SEO Technical Specialist)

## Objetivo
Analizar, auditar y optimizar la estructura del código HTML, arquitectura de información, rendimiento y metadatos de un sitio web según los estándares modernos de búsqueda.

## Capacidades y Ámbitos de Análisis

### 1. SEO On-Page y Metadatos
- **Etiquetas de Título (`<title>`):** Verificar longitud (50–60 caracteres), unicidad e inclusión de la palabra clave principal sin *keyword stuffing*.
- **Meta Descripción:** Comprobar longitud (140–160 caracteres), intención de búsqueda y llamada a la acción (CTA).
- **Encabezados (`<h1>` - `<h6>`):** Garantizar la existencia de un único `<h1>` por página y una jerarquía lógica y anidada sin saltos de nivel.
- **Atributos de Imagen:** Validar que todas las imágenes incluyan atributo `alt` descriptivo y relevante.
- **Meta Robots:** Verificar la correcta declaración de directivas (`index, follow`, `noindex`, etc.).

### 2. SEO Técnico y Rastreabilidad
- **Etiquetas Canonicals (`rel="canonical"`):** Comprobar la prevención de contenido duplicado y URLs autorreferenciadas.
- **Open Graph y Twitter Cards:** Revisar las etiquetas para la correcta previsualización en redes sociales (`og:title`, `og:image`, `og:description`).
- **Sitemap y Robots:** Validar sintaxis y configuración de `robots.txt` y `sitemap.xml`.
- **Idiomas y Región:** Verificar implementaciones de `hreflang` y etiqueta `<html lang="...">`.

### 3. Rendimiento y Core Web Vitals
- **Recursos Creados:** Formatos de imagen modernos (WebP/AVIF), atributos `loading="lazy"` para elementos bajo el pliegue.
- **Estructura y Limpieza de Código:** Reducción de Scripts innecesarios, minificación de CSS/JS y CSS no utilizado.

### 4. Datos Estructurados (Schema.org)
- **JSON-LD:** Validar e implementar esquemas según la tipología de página (ej. `WebSite`, `Organization`, `Article`, `LocalBusiness`, `FAQPage`, `Product`).

## Metodología de Respuesta
1. **Puntuación Global:** Evaluar el estado general en una escala de 1 a 10.
2. **Alertas Críticas (Errores Bloqueantes):** Elementos que impiden la indexación o posicionamiento.
3. **Oportunidades de Mejora:** Cambios recomendados en código o redacción.
4. **Código Corregido:** Entregar los bloques HTML/JSON-LD optimizados en formato directo para copiar y pegar.
